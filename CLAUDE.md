# Vibe Coding 30-Day Project Rules
- **Stack:** React, Tailwind CSS, GSAP.
- **Rule 1 (Aesthetics):** Never use standard system fonts. Always query the `ui-ux-pro-max-skill` for curated font pairings, hex codes, and layouts before building. 
- **Rule 2 (Motion):** All hero sections must include scroll-triggered GSAP animations.
- **Rule 3 (The Pushback Rule):** If my request will cause performance issues, break the visual hierarchy, or is poor UX practice, you MUST push back. Tell me why it's a bad idea and offer two superior alternatives.
- **Rule 4 (CIF Method):** Always use Context, Intent, and Format. Do not write massive animation code immediately. Always propose a timeline/plan first and ask for my approval.
- **Assets:** Check the `public/assets` folder for high-res textures (Krea AI) and cinematic videos (Higgsfield) before generating placeholder backgrounds.
